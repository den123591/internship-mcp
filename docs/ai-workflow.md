# Как проект делался вместе с AI

Как и [internship-radar](https://github.com/den123591/internship-radar/blob/main/docs/ai-workflow.md),
этот сервер собран в паре с Claude Code. Здесь записано, что пошло не по плану.

## Процесс

1. **Сначала проверить SDK, потом писать.** Установилась версия `mcp` 2.3, где `FastMCP` переименован в
   `MCPServer`, а часть API изменилась. Вместо того чтобы писать код по памяти (то есть под 1.x),
   агент прочитал исходники установленного пакета и сделал маленький прототип: один инструмент,
   один ресурс, один промпт и in-memory клиент. Так стало видно, в каком формате на самом деле
   приходит результат.
2. **Прототип показал важную деталь.** Обычное исключение в инструменте клиент видит как
   «Error executing tool boom», без текста ошибки. Поэтому все ожидаемые ошибки идут через
   `ToolError` с подсказкой агенту, что делать дальше.
3. **Логика отдельно от протокола.** `RadarService` ничего не знает про MCP, поэтому его легко
   тестировать и при желании можно повесить на другой интерфейс (HTTP, Telegram-бот).
4. **Проверка как у настоящего клиента.** После юнит-тестов сервер запускался отдельным процессом
   через stdio, так же как его запускает Claude Code, и работал на живых данных Хабра.

## Ошибки и находки

| Что случилось | Как починили |
|---|---|
| `ModuleNotFoundError: mcp.server.fastmcp` | Это переименование в SDK 2.x. Перешли на `mcp.server.mcpserver.MCPServer`, зафиксировали `mcp>=2.3,<3`. |
| Серверные тесты падали на teardown: «Attempted to exit cancel scope in a different task» | Async-фикстура pytest-asyncio закрывала клиент в другой задаче, а anyio так нельзя. Перешли на родной плагин anyio. |
| `ctx.info()` выдавал `MCPDeprecationWarning` | Логирование через MCP устарело в протоколе 2026-07-28. Заменили на `report_progress`. |
| Что будет, если Хабр недоступен? | Добавили тест: источник падает, а поиск продолжает отвечать из базы. |

## Что решал я

- Какие инструменты нужны агенту и как их назвать, чтобы модель выбирала правильный.
- Что поиск должен быть read-only, а обновление данных — отдельным явным действием.
- Что тексты вакансий — недоверенные данные, и это надо явно сказать модели.
